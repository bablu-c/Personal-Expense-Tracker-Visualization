🚀 Personal Expense Tracker & Visualization

An industry-level Personal Expense Tracker Dashboard built using Python, Streamlit, SQLite, Pandas, and Plotly.
This project helps users track daily expenses, analyze spending habits, monitor budgets, and visualize financial data through interactive charts.

📌 Features

✅ Add Daily Expenses
✅ Category-wise Expense Tracking
✅ Payment Method Tracking
✅ Interactive Dashboard
✅ Expense Analytics
✅ Budget Monitoring
✅ Estimated Savings Calculation
✅ SQLite Database Integration
✅ Plotly Visualizations
✅ Streamlit Web App Deployment
✅ Fully Responsive Dark UI

⚙️ Installation
1️⃣ Clone Repository
git clone https://github.com/bablu-c/Personal-Expense-Tracker-Visualization.git
2️⃣ Navigate to Project
cd Personal-Expense-Tracker-Visualization
3️⃣ Create Virtual Environment
python -m venv venv
4️⃣ Activate Virtual Environment
Windows
venv\Scripts\activate
Mac/Linux
source venv/bin/activate
5️⃣ Install Requirements
pip install -r requirements.txt
▶️ Run Application
streamlit run src/app.py
